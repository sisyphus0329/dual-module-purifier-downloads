# 双模块协同除味净化系统 V1.0

[进入 Windows 与安卓统一下载页面](https://github.com/sisyphus0329/dual-module-purifier-downloads/releases/latest)

双模块协同除味净化系统 V1.0 客户端安装包。

请在页面下方的 Assets 中选择对应平台的文件。

- Windows：下载 Purifier-Windows-x64-Setup.exe，适用于 Windows 10/11 64 位系统。
- 安卓：下载 Purifier-Android.apk，适用于 Android 8.0 及以上系统，不适用于 iPhone。
- Installation-zh-CN.txt 和 SHA256SUMS.txt 分别提供中文安装说明和完整性校验值。

Windows 安装程序未附发行者代码签名，安卓安装包使用开发签名。请核对下载来源及校验值后安装。安卓覆盖安装要求签名一致，卸载前请先导出需要保留的记录。

安装完成不等于已经接通装置。查看硬件实时数据需要配套主板与 ESP32-C3 网关程序、正确接线及实际通信。此处仅用于分发安装包，不提供公网控制装置的服务。
